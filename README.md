# OpenCode Viewer for Android

Приложение-обёртка: запускает `opencode serve` на телефоне через Termux и показывает интерфейс в нативном WebView — без браузера.

## Что делает

1. При запуске проверяет, отвечает ли сервер на `http://127.0.0.1:4096`
2. Если нет — запускает `opencode serve --port 4096 --hostname 127.0.0.1` через Termux `RUN_COMMAND`
3. Загружает интерфейс в полноэкранном WebView (темы и вид — те же, что в веб-версии)

## Сборка APK

Без Android SDK на телефоне — через GitHub Actions:

1. Загрузи этот каталог в свой репозиторий (или форкни здесь `main` ветку)
2. Открой вкладку **Actions** → выбери workflow **Build APK** → **Run workflow**
3. Дождись завершения, скачай артефакт `opencode-viewer-apk`
4. Установи `app-debug.apk` на телефон

## Установка на телефон

1. **Termux** установлен и `opencode` в `$PREFIX/bin/opencode` (`~ ../usr/bin/opencode`)
2. В `~/.termux/termux.properties` включён параметр:
   ```
   allow-external-apps = true
   ```
   После изменения — перезапусти Termux
3. Установи APK, открой приложение. При первом запуске Android спросит разрешения — дай их

## Требования

- Android 8.0+ (minSdk 26)
- Termux из F-Droid с установленным opencode
- Если порт 4096 занят — поменяй `PORT` в `MainActivity.kt`

## Заметки

- Сервер живёт только пока Termux не убит системой. Если сервер упал — просто открой приложение снова, оно его перезапустит
- `serve --port 0` (случайный порт) не используется: приложение ждёт фиксированный порт 4096
