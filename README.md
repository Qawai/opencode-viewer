# OpenCode Viewer for Android

Готовый Android-клиент для [opencode](https://opencode.ai) — сама программа вшита внутрь APK и запускается на телефоне, интерфейс показывается в нативном WebView. **Termux и браузер не нужны.**

## Возможности

- Встроенный opencode: сервер поднимается приложением на `127.0.0.1:4096` автоматически
- Чёрный фон с анимацией при загрузке, тёмная тема интерфейса
- Подключение к любому существующему серверу на порту 4096, если он уже запущен
- Настройка API-ключа прямо в приложении (кнопка кружок в правом верхнем углу)
- API-ключ указывается один раз, хранится в `auth.json` приложения

## Установка (без Termux)

### Простой способ — скачать прямо отсюда
APK лежит прямо в репозитории: **[apk/OpenCode-Viewer.apk](apk/OpenCode-Viewer.apk)** — нажми, затем кнопку **Download** (или «Скачать»). Устанавливай.

Или открой вкладку **Releases** наверху страницы — там всегда лежит последняя версия APK с кнопкой для скачивания.

### Через GitHub Actions (если нужно собрать свежую версию)
1. Открой вкладку **Actions** наверху страницы репозитория
2. Слева выбери workflow **Build APK**
3. Выбери самый верхний (последний) запуск с зелёной галочкой
4. Прокрути вниз до раздела **Artifacts** → нажми `OpenCode-Viewer.apk` — скачается zip
5. Распакуй zip — внутри сам APK

Затем:
1. Установи APK на телефон (разреши установку из неизвестных источников)
2. Открой приложение:
   - при первом запуске появится окно «Первая настройка» с инструкцией
   - нажми **«Ввести ключ»** и вставь API-ключ своего провайдера ИИ (`sk-...`)
   - приложение само распакует opencode, поднимет сервер и откроет интерфейс

> Первый запуск дольше обычного: из APK распаковывается ~180 МБ исполняемого файла. Нужно ~180 МБ свободного места.

> **⚠️ Браузер предупреждает «файл может быть опасен» — это нормально.** Chrome так пишет про любой APK, которого нет в Google Play: APK — исполняемый файл, ставится вручную в обход Play Маркета, а этот релиз собран твоим личным ключом, а не Google. Это стандартное предупреждение, одно и то же для всех APK с любых сайтов. **Эта сборка безопасна**: она собирается в GitHub Actions из открытого исходника (весь код — в этом репозитории), внутри просто opencode + WebView. Если хочешь, можешь сверить размер/хэш или посмотреть `MainActivity.kt` — APK собран ровно из него. На вопрос «Установить всё равно?» можно смело отвечать «Да».

## Смена ключа

Нажми круглую кнопку ⚙ в правом верхнем углу экрана → вставь новый ключ → «Сохранить».

## Требования

- Android 8.0+ (minSdk 26)
- ~180 МБ свободного места для первого запуска
- API-ключ провайдера ИИ (Anthropic, OpenAI, OpenRouter и т.д.)

## Логи

Если что-то не работает, логи приложения пишутся в `Logcat` (тег `OpencodeViewer`) и в `/sdcard/Download/opencode-viewer-crash.log*`.
